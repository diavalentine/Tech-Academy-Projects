# JAVASCRIPT-PROJECTS
A repository for my JavaScript projects

## Projects

- Basic JavaScript Projects - Ten small exercises covering JavaScript basics like functions, math operators, string methods, loops, and arrays.
- Advanced JavaScript Projects - A switch statement exercise and a working calculator.
- TicTacToe - A Tic Tac Toe game that runs in the browser.
- Pizza_Project - A pizza ordering page that builds a receipt and total from the options you pick.
- jQuery - A classic cars page that uses jQuery animations and effects.
- todo_app - A to-do list that saves your tasks in the browser.
- debug-code.html - Practice using the browser console to debug code.
- running-javascript-in-the-console.html - Practice running JavaScript in the browser console.
